## What I'm building

### [SCREWED](https://nerdycaesar.itch.io/screwed)
A multiplayer social sabotage game set in an office, where Workers and Saboteurs compete over a shared project and a ticking deadline.

- **Design:** counter-chain mechanics, player agency, risk/reward, and meaningful responses to opposing abilities.
- **Engineering:** Unity and C#, Netcode for GameObjects, Multiplayer Services and Relay, lobby player events, synchronized gameplay state, and gameplay abilities.
- **Ongoing work:** refining session and player lifecycles, debugging networking behavior, and iterating on mechanics.

### Unreal Engine level-design prototype
A prototype built during a level-design bootcamp, exploring level construction, Blueprint visual scripting, and materials.

### [F1 Pit Stop Optimization](https://github.com/nerdyCaesar/F1-Pit-Stop-Optimization)
A Python project that predicts next-lap pit stops from Formula 1 race data using a random forest classifier. It combines data preparation, race-grouped cross-validation, and a Streamlit dashboard for comparing predictions with recorded stops.

### [FlappyRed](https://github.com/nerdyCaesar/FlappyRed-UnityLearn)
An early Unity project where I practiced game-development fundamentals and experimented with my own variations.
